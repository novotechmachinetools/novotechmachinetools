How to read this edition

This is EUROSTAMP's own catalogue, page for page, with the inch values added by NovoTech. Nothing is taken away: every metric number keeps its place and the imperial value stands beside it, in the same type and colour.

Punch 1055 on page 36: dimensions, the squared scale under the tool, the specification lines and the length box, each in millimetres and inches.

What was added

  • Dimensions on the drawings: the inch value in brackets beside the millimetres — 105 (4.13″), R 0,5 (.020″). Two decimals from one inch up, three below.
  • The squared scale round each punch: every numbered mark with its inch value — 20 (.79″), 40 (1.57″).
  • Specification lines: height and radius in inches — H = 105.00 (4.134″), R = 0.5 (.020″).
  • Length boxes: every length in inches and every weight in pounds, in a twin box beside the metric one or inside the same cells — 835 mm / 32.87″, 12,6 kg / 27.8 lb.
  • FRAZ. / SECT. marks a sectioned set: pieces that add up to the length, with horns at the ends.
  • Where a drawing has no room beside a number — a small radius deep inside a 4V die, say — the number keeps its millimetres only: 1 mm = .0394″.
  • The page numbers are EUROSTAMP's, so the product index on pages 8 – 13 still leads to every code.
